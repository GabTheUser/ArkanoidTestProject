# Arkanoid Prototype

Небольшая игра в жанре Arkanoid, выполненная в Unity.  
В проекте есть три уровня, которые переключаются по кругу. Кирпичи спавнятся на заранее заданных точках, выбираются из набора разных префабов.
Уровни с легкостью можно добавлять новые

Сыграть можно здесь: https://gamejolt.com/games/PingPongNoid/1030784 (Вэб версия)
Видео демо тут: https://disk.yandex.ru/i/Vfq0AXbyCIIlKg

## Что реализовано
- Управление с клавиатуры и тач-жестов.
- Разные типы кирпичей, каждый со своими эффектами, звуками и стадиями повреждений.
- Бафф-кирпич, который временно увеличивает урон мяча.
- Подсчёт общего счёта, сохраняющегося между уровнями.
- Поп-апы очков, звуки ударов, визуальные эффекты разрушения.
- Экран старта и экран завершения с кнопками «Рестарт» и «Следующий уровень».

Проект делался как тестовое задание, чтобы показать владение Unity, C#, Scriptable Input System, событиями, наследованием и общей архитектурой геймплея.
